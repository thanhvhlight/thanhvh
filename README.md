# Quick VietQR

Ứng dụng Next.js tạo nhanh QR chuyển khoản ngân hàng.

## Chạy local

```bash
npm install
npm run dev
```

Mở http://localhost:3000

## Đưa lên Vercel

1. Upload toàn bộ thư mục lên GitHub.
2. Import repository vào Vercel.
3. Giữ mặc định Framework Preset: Next.js.
4. Bấm Deploy.

Không cần database và không cần biến môi trường.
