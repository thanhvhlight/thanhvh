# Quick VietQR – Node.js 24

Ứng dụng Next.js tạo mã QR chuyển khoản VietQR.

## Yêu cầu

- Node.js 24.x
- npm 11+

## Chạy local

```bash
npm install
npm run dev
```

Mở http://localhost:3000

## Deploy Vercel

1. Đưa toàn bộ mã nguồn lên GitHub.
2. Import repository vào Vercel.
3. Framework Preset: Next.js.
4. Node.js Version: 24.x.
5. Deploy.

Không cần Environment Variables hoặc database.
