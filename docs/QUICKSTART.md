# Quick start

1. Chạy `supabase/schema.sql` trong Supabase SQL Editor và sửa tài khoản ngân hàng mẫu.
2. Upload project lên GitHub.
3. Import vào Vercel, chọn Node.js 24.x.
4. Thêm các biến trong `.env.example`.
5. Redeploy rồi mở `/setup` để kết nối webhook.
6. Nhắn bot: `+10tr anh son`.

Trang `/banks` dùng `ADMIN_SETUP_KEY` để thêm tài khoản ngân hàng.
